DTLcompare - Guide utilisateur

Guide d'utilisation de DTLcompare pour comparer deux diagnostics distants DTLknowsWhy.

Snapshots JSONSMBRapports HTML / TXT / JSON

Objectif

DTLcompare sert a comprendre pourquoi un acces distant fonctionne depuis un poste mais echoue depuis un autre. Il ne lance pas le diagnostic lui-meme : il analyse deux fichiers JSON deja produits par DTLknowsWhy.

Preparer les fichiers

  1. Produire un snapshot DTLknowsWhy depuis le poste ou l'acces fonctionne.
  2. Produire un second snapshot depuis le poste ou l'acces echoue.
  3. Verifier que les deux diagnostics ciblent le meme serveur, la meme machine ou le meme partage.
  4. Placer les deux fichiers JSON dans un dossier accessible depuis l'environnement Python.

Lancer l'analyse

L'analyse se lance en indiquant d'abord le snapshot fonctionnel, puis le snapshot en echec.

python comparative_analysis.py working_snapshot.json failing_snapshot.json

Exemple :

python comparative_analysis.py 172.17.7.19_snapshot_20260610_151730.json 172.17.7.19_snapshot_20260610_152617.json

Rapports produits

Rapport HTML

Document principal pour la lecture humaine et le partage avec une equipe support ou infrastructure.

Rapport texte

Synthese compacte utilisable dans un ticket, un courriel ou une note d'intervention.

Rapport JSON

Version structuree pour archivage, reprise automatique ou comparaison ulterieure.

Lire l'analyse

  • Causes probables : hypotheses classees avec preuves et score de pertinence.
  • Causes eliminees : pistes que les donnees permettent d'ecarter.
  • Preuves : faits extraits des snapshots, comme ping, TCP 445, partages visibles ou messages d'erreur.
  • Remediation : action conseillee lorsque l'analyse permet de proposer une suite logique.

Options utiles

--lang fr|en
--json
--output-prefix chemin/rapport
--no-files

--output-prefix permet de choisir le nom et l'emplacement des rapports. --no-files limite la sortie a la console, utile pour un test rapide.

Depannage

  • Si l'import expert.compare echoue, lancer DTLcompare dans un environnement ou DTLknowsWhy est disponible.
  • Si les resultats semblent incoherents, verifier que les deux snapshots ciblent exactement le meme acces.
  • Si aucun rapport n'apparait, verifier le dossier courant, les droits d'ecriture et l'usage eventuel de --no-files.
  • Si l'analyse signale une cible differente, refaire les deux diagnostics avec la meme cible.
